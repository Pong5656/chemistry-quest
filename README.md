# ⚗️ CHEMQUEST 8-BIT — ผจญภัยเรียนเคมี ม.ปลาย

เกมเรียนเคมีระดับชั้นมัธยมปลาย (ตามหลักสูตร สสวท./IPST) สไตล์เกมแฟมิคอมยุค 8-bit — เดินทางบนแผนที่โลก 6 เล่ม 14 บท ผ่าน 5 โซนภารกิจต่อบท พร้อมเก็บ XP เลเวล ฉายา และเหรียญตรา!

## 🗺️ 5 โซนภารกิจต่อบท (ปลดล็อกเรียงลำดับ)

| โซน | ชื่อ | คำอธิบาย |
| --- | --- | --- |
| 🧑‍🏫 | เรียนกับ NPC | รับภารกิจจาก NPC + อ่านสไลด์บทเรียน (หัวข้อ/สูตร/เทคนิคลัด/ตาราง) |
| 🧩 | พัซเซิลเช็คความเข้าใจ | คำถามหลากรูปแบบ: จับคู่ · เติมคำ · ลากวาง · เรียงลำดับ · จริง/เท็จ |
| 🕹️ | มินิเกมแพลตฟอร์มเมอร์ | วิ่งกระโดดเก็บอะตอมบนเวทีพิกเซล ผลลัพธ์เพิ่มพลังให้สู้บอส |
| ⚔️ | บอสสอบ | เผชิญบอส ตอบข้อสอบ 3 คลื่นความยาก (~22 ข้อ) ยิงพลังงานโจมตี — ใช้ไอเท็มที่เก็บได้ |

มีชุดไอเท็มในเกม: ❤️ ฮาร์ต ⛨ ชิลด์ ❌ กันตอบผิด 50% 🧪 ตารางธาตุ ⏱️ ขยายเวลา และเครื่องคิดเลขวิทยาศาสตร์ (SciCalc) ในตัว

## 📚 เนื้อหา (14 บท · ครบ ม.4–ม.6)

ม.4 เล่ม 1: ความปลอดภัยในแล็บและทักษะปฏิบัติ · อะตอมและตารางธาตุ · พันธะเคมี — ม.4 เล่ม 2: ปริมาณสัมพันธ์ · สารละลาย · แก๊ส — ม.5 เล่ม 1: อัตราการเกิดปฏิกิริยา · สมดุลเคมี · กรด–เบส — ม.5 เล่ม 2: เคมีไฟฟ้า · เคมีอินทรีย์ — ม.6 เล่ม 1: เชื้อเพลิงซากดึกดำบรรพ์และเคมีพอลิเมอร์ · การวิเคราะห์เชิงปริมาณ — ม.6 เล่ม 2: เปรียบเทียบนโยบายเคมีสีเขียวกับเคมีอื่นๆ

> เนื้อหาแต่ละบทอยู่ใน `src/data/ch{บท}.ts` — แก้/เพิ่มได้โดยตรง (ดู type ใน `src/types.ts`)

## 🛠️ เทคโนโลยี

- Vite 7 + React 19 + TypeScript (Tailwind CSS v4)
- ธีม 8-bit — ฟอนต์ Press Start 2P + Chakra Petch + Sarabun
- มินิเกมแพลตฟอร์มเมอร์บน **Canvas API** (`src/components/Platformer.tsx`), เอฟเฟกต์เสียง Web Audio (`src/lib/sfx.ts`)
- Build เป็น **ไฟล์ HTML เดียว** (`vite-plugin-singlefile`) → Deploy ได้ทุกที่ (Vercel / Netlify / GitHub Pages)
- เซฟความคืบหน้า + XP ใน **localStorage ล้วน** (key `chemquest8bit.progress.v2`, `chemquest.player.v1`) — ไม่ต้องใช้ฐานข้อมูล

## 🚀 เริ่มพัฒนา

```bash
npm install
npm run dev        # dev server ที่ http://localhost:5173
npm run build      # build production → dist/index.html (ไฟล์เดียว)
npm run preview    # ดูผล build ในเครื่อง
npm run typecheck  # tsc --noEmit
```

## ☁️ Deploy บน Vercel

1. push โค้ดขึ้น GitHub
2. เปิด [vercel.com/new](https://vercel.com/new) → **Add New Project** → import repo → **Deploy**
   (Vercel ตรวจพบว่าเป็น Vite ให้อัตโนมัติ: build `npm run build`, output `dist`)
